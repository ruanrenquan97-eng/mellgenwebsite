- **原料报送版本号升级规范**：
  1. **次版本号变更（例如：版本 1.0 -> 1.1 / 2.0 -> 2.1）**：
     - 原料定性成分及定量组成百分比保持不变；

  2. **主版本号变更（例如：版本 1.0 -> 2.0 / 2.0 -> 3.0）**：
     - 原料核心有效组分浓度调整、溶剂体系变更（如水溶剂调整为复合多元醇低水活度体系）；
     - 复合引入中科大第3代cTDP环肽作为生物促透伴侣载体；
